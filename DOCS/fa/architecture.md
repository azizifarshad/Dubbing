# معماری فنی و ساختار امنیتی دوبله ویدانس

این سند تشریح‌کننده معماری سیستم، مدل تفکیک کلیدهای رمزنگاری، لایه‌های پردازش صوت و ویدیو و ساختار چندکاربره نرم‌افزار **دوبله ویدانس** است.

---

## ۱. نمای کلی معماری نرم‌افزار

دوبله ویدانس مبتنی بر معماری دسکتاپ مدرن و هیبریدی است:

```mermaid
graph TD
    subgraph لایه برنامه کاربردی
        Launcher["لانچر بومی ویندوز\n(DubbingVidans.exe)"]
        UI["رابط کاربری مدرن\n(React 19 + TypeScript + Vite)"]
        Server["سرور پس‌زمینه محلی\n(Node.js + Express روی 127.0.0.1:3000)"]
    end

    subgraph موتورهای پردازش محلی
        FFmpeg["FFmpeg و FFprobe\n(استخراج، میکس، فیلترگراف و Ducking)"]
        Whisper["Faster-Whisper\n(تبدیل صوت به متن کاملاً آفلاین)"]
        Mux["mux_video.py\n(پایپ‌لاین برندینگ و تولید ویدیوی نهایی)"]
    end

    subgraph هویت سخت‌افزاری و ذخیره‌سازی
        HwEngine["موتور شناسایی مشخصات سخت‌افزاری\n(CPU, BIOS UUID, Disk Serial, MachineGuid)"]
        ProgramData["C:\\ProgramData\\DubbingVidans\n(محل ذخیره لایسنس دائمی مستقل از آپدیت‌ها)"]
    end

    subgraph زیرساخت توزیع آپدیت
        UpdateServer["سرور گیت‌وی آپدیت (update-server/)\n(پراکسی احراز هویت با گیت‌هاب)"]
        PrivateRepo["مخزن خصوصی گیت‌هاب\n(azizifarshad/Dubbing)"]
    end

    Launcher --> Server
    Launcher --> UI
    UI -->|REST API| Server
    Server --> FFmpeg
    Server --> Whisper
    Server --> Mux
    Server --> HwEngine
    HwEngine --> ProgramData

    UpdateServer -->|GitHub App / PAT| PrivateRepo
```

## ۲. مدل تفکیک کلیدهای رمزنگاری (Cryptographic Isolation)

یکی از الزامات حیاتی پروژه، تفکیک ۱۰۰٪ کلید لایسنس نرم‌افزار از کلید امضای بسته‌های آپدیت است:

| کلید رمزنگاری | الگوریتم | کاربرد و وظیفه | محل نگهداری | سطح امنیت و محرمانگی |
| :--- | :--- | :--- | :--- | :--- |
| **کلید خصوصی مالک لایسنس** | Ed25519 | صدور و امضای لایسنس‌های مشتریان (`.vidanslic`) | فقط سیستم مالک نرم‌افزار | **هرگز در گیت، اکشن‌ها یا سورس توزیعی قرار نمی‌گیرد.** |
| **کلید عمومی رسمی لایسنس** | Ed25519 | اعتبارسنجی لایسنس در کلاینت کاربر | در `src/utils/licenseConfig.ts` | کاملاً حفظ شده و بدون تغییر باقی مانده است. |
| **کلید خصوصی امضای آپدیت** | Ed25519 | امضای مانیفست انتشار نسخه جدید | سکرت مخزن گیت‌هاب `UPDATE_SIGNING_PRIVATE_KEY` | **کاملاً مستقل از کلید لایسنس.** |
| **کلید عمومی امضای آپدیت** | Ed25519 | تأیید امضای مانیفست آپدیت در کلاینت | در `src/utils/updateConfig.ts` | کلید اختصاصی؛ مانع از امضای آپدیت با کلید لایسنس. |
| **کلید هویت دستگاه** | Ed25519 | امضای درخواست فعال‌سازی دستگاه (`.vidansreq`) | در `C:\ProgramData\DubbingVidans` | به شکل رمزنگاری‌شده با الگوریتم AES-256-GCM ذخیره می‌شود. |

---

## ۳. معماری ذخیره‌سازی چندکاربره لایسنس در ویندوز

اطلاعات لایسنس و هویت دستگاه در مسیر زیر نگهداری می‌شود:
`C:\ProgramData\DubbingVidans`

- این پوشه در دسترس تمامی حساب‌های کاربری فعال در ویندوز قرار دارد.
- بسته‌های آپدیت و نصاب نرم‌افزار تحت هیچ شرایطی این دایرکتوری را بازنویسی یا پاک نمی‌کنند.
- فایل لایسنس حتی پس از حذف یا ارتقای نرم‌افزار دست‌نخورده باقی می‌ماند.
