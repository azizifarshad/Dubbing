# راهنمای جامع پیکربندی و متغیرهای محیطی

این سند کلیه تنظیمات پیکربندی، متغیرهای فایل محیطی (`.env`)، مسیرهای اتصال و نحوه عملکرد مؤلفه‌های نرم‌افزار **دوبله ویدانس** را توضیح می‌دهد.

---

## ۱. تنظیمات برنامه کلاینت ویندوز (`.env`)

نرم‌افزار دسکتاپ هنگام راه‌اندازی، پارامترهای خود را از فایل `.env` واقع در دایرکتوری ریشه برنامه می‌خواند.

### جدول متغیرهای محیطی کلاینت

| نام متغیر | مقدار پیش‌فرض | توضیحات فنی |
| :--- | :--- | :--- |
| `PORT` | `3000` | پورت محلی TCP که سرور پس‌زمینه بر روی آن به درخواست‌ها گوش می‌دهد. |
| `HOST` | `127.0.0.1` | آدرس اینترفیس شبکه (جهت امنیت محلی به لوپ‌بک محدود است). |
| `API_BASE_URL` | `https://api.hormouz.net/v1` | نشانی پایه ارائه‌دهنده خدمات هوش مصنوعی هرمز یا APIهای سازگار با OpenAI. |
| `HORMOUZ_API_KEY` | *(خالی)* | کلید احراز هویت متصل به سرویس هرمز جهت ترجمه و دوبله. |
| `TRANSLATION_MODEL` | `openai/gpt-6-luna` | مدل پیش‌فرض ترجمه متن و نگهداری بافت معنایی زیرنویس. |
| `TTS_MODEL` | `google/gemini-3.8-flash-lite-tts` | شناسه مدل تولید صدای دوبله فارسی. |
| `GEMINI_API_KEY` | *(خالی)* | کلید API مستقیم گوگل جمینای (در صورت اتصال مستقیم به جمینای). |
| `UPDATE_SERVER_URL` | `http://localhost:4000` | آدرس گیت‌وی سرور به‌روزرسانی برای کاربران نهایی. |

### نمونه فایل `.env`
```env
# تنظیمات پورت و رابط شبکه محلی
PORT=3000
HOST=127.0.0.1

# اتصال به موتور هوش مصنوعی هرمز
API_BASE_URL=https://api.hormouz.net/v1
HORMOUZ_API_KEY=your_hormouz_api_key_here
TRANSLATION_MODEL=openai/gpt-6-luna

# تنظیمات تبدیل متن به صدا (TTS)
TTS_MODEL=google/gemini-3.8-flash-lite-tts
GEMINI_API_KEY=

# گیت‌وی به‌روزرسانی چندکاربره
UPDATE_SERVER_URL=https://updates.vidans.ir
```

## ۲. تنظیمات سرور گیت‌وی آپدیت (`update-server/.env`)

سرور گیت‌وی آپدیت در نقش پراکسی امن میان کلاینت‌های دسکتاپ و مخزن خصوصی گیت‌هاب عمل می‌کند تا توکن گیت‌هاب هرگز در دسترس کاربران نهایی قرار نگیرد.

| نام متغیر | مقدار پیش‌فرض | توضیحات فنی |
| :--- | :--- | :--- |
| `PORT` | `4000` | پورت اجرای سرویس پراکسی گیت‌وی. |
| `GITHUB_REPO_OWNER` | `azizifarshad` | نام مالک یا سازمان گیت‌هاب. |
| `GITHUB_REPO_NAME` | `Dubbing` | نام مخزن خصوصی. |
| `GITHUB_APP_ID` | *(اختیاری)* | شناسه اپلیکیشن گیت‌هاب جهت احراز هویت امن سازمانی. |
| `GITHUB_APP_INSTALLATION_ID` | *(اختیاری)* | شناسه نصب اپلیکیشن روی مخزن. |
| `GITHUB_APP_PRIVATE_KEY` | *(اختیاری)* | کلید خصوصی RS256 جهت صدور خودکار توکن‌های کوتاه‌مدت. |
| `GITHUB_TOKEN` | *(اختیاری)* | توکن دسترسی شخصی (PAT) با دسترسی خواندن مخزن به عنوان جایگزین. |
| `REQUIRE_LICENSE_AUTH` | `false` | الزام ارسال هدر `X-Hardware-Fingerprint` برای دانلود آپدیت. |
