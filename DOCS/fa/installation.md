# راهنمای نصب و استقرار نرم‌افزار دوبله ویدانس

این سند شامل راهنمای جامع نصب، پیکربندی و اجرای نرم‌افزار **دوبله ویدانس (Dubbing Vidans)** بر روی سیستم‌عامل‌های پشتیبانی‌شده و محیط‌های توسعه است.

---

## ۱. سیستم‌عامل‌ها و نیازمندی‌های سخت‌افزاری

| سیستم‌عامل | معماری پردازنده | حالت استقرار | حداقل نیازمندی‌ها |
| :--- | :--- | :--- | :--- |
| **ویندوز ۱۰ / ۱۱ / سرور** | `x64` (۶۴ بیتی) | **کلاینت بومی و پورتابل** | دات‌نت ۴.۵+، ۴ گیگابایت رم، ۲ گیگابایت حافظه |
| **مک‌اواس ۱۲+** | `x64` / `arm64` | محیط ترمینال و استودیو وب | نودجی‌اس ۱۸+، پایتون ۳.۱۰+، FFmpeg |
| **لینوکس (اوبونتو/دبیان)** | `x64` | محیط ترمینال و استودیو وب | نودجی‌اس ۱۸+، پایتون ۳.۱۰+، FFmpeg |

---

## ۲. نصب برای کاربران نهایی ویندوز (بسته نصبی استاندارد)

بسته نصبی استاندارد و رسمی نرم‌افزار در قالب فایل `Dubbing-Vidans-Setup.exe` توزیع می‌شود.

### مراحل نصب:
۱. فایل نصبی رسمی `Dubbing-Vidans-Setup.exe` را دانلود نمایید.
۲. روی فایل کلیک‌راست کرده و گزینه **Run as administrator** را انتخاب کنید (جهت مقداردهی دسترسی دایرکتوری اشتراکی `C:\ProgramData\DubbingVidans`).
۳. مراحل ویزارد نصب را دنبال کنید:
   - شرایط توافق‌نامه لایسنس اختصاصی نرم‌افزار را تأیید کنید.
   - مسیر پیش‌فرض نصب `C:\Program Files\Dubbing Vidans` است.
   - آیکون برنامه بر روی دسکتاپ و منوی استارت ایجاد می‌گردد.
۴. نرم‌افزار را از طریق میانبر دسکتاپ اجرا نمایید.
۵. لانچر بومی ویندوز (`DubbingVidans.exe`) سرویس پس‌زمینه را روی `127.0.0.1:3000` اجرا کرده و مرورگر پیش‌فرض را باز می‌کند.

---

## ۳. اجرای پورتابل (بدون نیاز به نصب)

دوبله ویدانس به صورت کامل از اجرای پرتابل پشتیبانی می‌کند:
۱. بسته فشرده پرتابل را در مسیر دلخواه (مثلاً `D:\DubbingVidans`) استخراج کنید.
۲. فایل `DubbingVidans.exe` یا اسکریپت `Start-DubbingVidans.bat` را اجرا نمایید.
۳. در حالت پرتابل:
   - لایسنس سخت‌افزاری همچنان در مسیر ماشین `C:\ProgramData\DubbingVidans` (یا پوشه پشتیبان `.license_data`) نگهداری می‌شود.
   - تنظیمات و پروژه‌های کاری در همان پوشه پرتابل حفظ می‌شوند.

## ۴. راه‌اندازی محیط توسعه برای برنامه‌نویسان (از سورس‌کد)

### پیش‌نیازها:
- **Node.js:** نسخه ۱۸ یا بالاتر (پیشنهادی ۲۰+)
- **npm:** نسخه ۹ یا بالاتر
- **Python:** نسخه ۳.۱۰ یا بالاتر همراه با `pip`
- **FFmpeg:** نصب و ثبت‌شده در متغیر محیطی `PATH` سیستم
- **کامپایلر سی‌شارپ (`csc.exe`):** موجود به طور پیش‌فرض در دات‌نت ویندوز

### دستورات راه‌اندازی گام‌به‌گام:
```powershell
# ۱. دریافت سورس‌کد مخزن خصوصی
git clone https://github.com/azizifarshad/Dubbing.git
cd Dubbing

# ۲. نصب وابستگی‌های جاوااسکریپت از روی lockfile
npm ci

# ۳. نصب وابستگی‌های پایتون
pip install cryptography soundfile numpy faster-whisper

# ۴. کپی فایل نمونه متغیرهای محیطی
cp .env.example .env

# ۵. کامپایل رابط کاربری Vite و باندل سرور
npm run build

# ۶. اجرای تست‌های سبک و اعتبارسنجی
npm run test:ci

# ۷. اجرای سرور توسعه با بارگذاری خودکار
npm run dev
```
