# بخش ۵: مقایسه جامع مخزن گیت‌هاب و پروژه محلی ویندوز (Dubbing Vidans)

## ۱. وضعیت اتصال مخزن گیت و شاخه‌ها

این ممیزی به مقایسه دقیق میان کدهای مخزن گیت‌هاب به نشانی `https://github.com/azizifarshad/Dubbing.git` و ساختار محلی دایرکتوری در ویندوز می‌پردازد:

- **آدرس مخزن ریموت**: `https://github.com/azizifarshad/Dubbing.git`
- **شاخه محلی فعال**: `main` (کاملاً سینک با `origin/main` در کامیت `f2ceb60`)
- **وضعیت Working Copy**: پاک و بدون تغییر در فایل‌های ردیابی‌شده (`git diff` خالی است).
- **تعداد فایل‌های ردیابی‌شده در گیت**: ۱۲۶ فایل.
- **تعداد کل فایل‌های غیرسیستمی محلی**: ۲۱۲ فایل.

## ۲. دسته‌بندی تفاوت‌های محلی با مخزن گیت‌هاب

### ۲.۱. فایل‌های ردیابی‌نشده (Untracked)
تنها یک پوشه ردیابی‌نشده در `git status` وجود دارد:
- **`Dubb/`**: این پوشه حاصل یک کلون ناخواسته از آدرس `https://github.com/azizifarshad/Dubb.git` در ریشه پروژه است که دیتابیس گیت مجزای خود را دارد. این پوشه جزو پروژه ویدانس نیست و باید حذف شود.

### ۲.۲. فایل‌های محلی نادیده‌گرفته‌شده (Git-Ignored)
این فایل‌ها و پوشه‌ها عمداً در گیت کامیت نشده‌اند تا امنیت پروژه حفظ شده یا حجم مخزن افزایش نیابد:

| مسیر فایل یا پوشه | حجم محلی | علت وجود و اهمیت در سیستم |
| :--- | :--- | :--- |
| `.env` | ۸۶۴ بایت | تنظیمات پورت و آدرس‌های محلی بدون افشای کلیدها |
| `Dubbing-Vidans-Setup.exe` (ریشه) | ۳۶۵.۰ مگابایت | نسخه قدیمی کامپایل‌شده نصاب (تاریخ ۹ نوامبر). تکراری است و فضای دیسک را اشغال کرده. |
| `Sadra/` | ۸۵۸.۴ مگابایت | بسته تحویل پروژه به مشتری. **هشدار**: کلید خصوصی مالک در این پوشه است و باید خارج شود! |
| `scratch/` | ۷.۲ کیلوبایت | اسکریپت‌های موقت تست ترجمه توسط برنامه‌نویس |
| `models/` | ۱۴۱.۲ مگابایت | وزن‌های مدل هوش مصنوعی ویسپر برای کارکرد ۱۰۰٪ آفلاین تبدیل گفتار به متن |
| `runtime/` | ۸۷۰.۰ مگابایت | مفسر مستقل پایتون، اف‌اف‌ام‌پگ و نود جهت بی‌نیازی مشتری از نصب نرم‌افزارهای جانبی |
| `build/` | ۵۲.۰ مگابایت | کش باقیمانده از بیلد آزمایشی PyInstaller |
| `dist/` | ۱۲.۷ مگابایت | خروجی کامپایل‌شده فرانت‌اند Vite برای سرو وب |
| `dist-installer/` | ۳۴۸.۱ مگابایت | نصاب رسمی و نهایی نسخه 1.0.1 همراه با امضای دیجیتال و هش‌ها |
| `LicenseGenerator.exe` | ۱۶.۱ مگابایت | نرم‌افزار گرافیکی ویندوز جهت صدور لایسنس دائمی برای مشتریان |
| `owner_private_key.pem` | ۱۲۲ بایت | کلید خصوصی مالک جهت صدور لایسنس (فوق‌محرمانه) |
| `update_signer_private_key.pem` | ۱۱۹ بایت | کلید خصوصی امضای آپدیت‌های جدید (فوق‌محرمانه) |

- **صفر**: تمامی ۱۲۶ فایل ثبت‌شده در گیت‌هاب، روی دیسک محلی نیز موجود و منطبق هستند.

### ۲.۴. فایل‌های ویرایش‌شده نسبت به گیت‌هاب
- **صفر**: هیچ فایلی نسبت به کامیت آخر شاخه main دستکاری نشده است.

## ۳. تحلیل تکرار فایل‌ها و بهینه‌سازی دیسک

1. **فایل‌های نصاب چندگانه**: سه فایل `Dubbing-Vidans-Setup.exe` در ریشه، در `Sadra/` و در `dist-installer/` وجود دارد که مجموعاً بیش از ۱ گیگابایت فضا گرفته‌اند. تنها نسخه `dist-installer/` نسخه رسمی و به‌روز 1.0.1 است.
2. **فایل‌های تصویری و ویدیویی تکراری**: ویدیوی ۵.۴۵ مگابایتی اینتروی استودیو با نام‌های `Final  (1).mp4` و `intro.mp4` هم در پوشه `assets/` و هم در پوشه `public/assets/` عیناً تکرار شده است. همچنین لوگوی واترمارک با نام‌های گوناگون سه بار تکرار شده است.
